# 1. 赋值表达式

对于表达式`expr1 op = expr2`，展开应该为`expr1 = (expr1) op (expr2)`。
例如：`x *= y + 1`展开应该为`x = x * (y + 1)`，而不是`x = x * y + 1`。

# 2. 三目运算符

`x = expr1 ? expr2 : expr3`的意思是，首先计算expr1，如果其值不等于0（为真），则计算expr2的值，并以该值作为条件表达式的值，否则计算expr3的值，并以该值作为条件表达式的值。expr2与expr3中只能有一个表达式被计算。

注意的是，这本身是一种表达式，其返回类型由expr2和expr3的类型共同决定。如果二者类型不同，则转换类型与操作数的转换规则一致
