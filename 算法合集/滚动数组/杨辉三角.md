给定一个非负索引 `rowIndex`，返回「杨辉三角」的第 `rowIndex` 行。在「杨辉三角」中，每个数是它左上方和右上方的数的和。

### 我的答案

```c++
vector<int> getRow(int rowIndex) {
	if (rowIndex == 0) return {1};
    if (rowIndex == 1) return {1 , 1};
    else {
        vector<int> last = getRow(rowIndex - 1);
        vector<int> now (rowIndex + 1);
        for (int i = 0 ; i < rowIndex + 1 ; i ++) {
	        if (i == 0 || i == rowIndex) now[i] = 1;
	        else now[i] = last[i] + last[i - 1];
	    return now;
    }    
}
```

问题：

采用递归算法，消耗内存过大，需要存储整个三角形，空间复杂度是O(rowIndex²)。

### 滚动数组

```c++
vector<int> getRow(int rowIndex) {
    vector<int> pre, cur;
    for (int i = 0; i <= rowIndex; ++i) {
        cur.resize(i + 1);
        cur[0] = cur[i] = 1;
        for (int j = 1; j < i; ++j) {
            cur[j] = pre[j - 1] + pre[j];
        }            
        pre = cur;
    }
    return pre;
}
```

优点：**显著减少内存使用**： 二维 → 一维：O(m×n) → O(n) ；二维 → 两行：O(m×n) → O(2n)

缺点：1. **可能丢失中间结果**：如果需要回溯或访问历史数据，无法做到。
