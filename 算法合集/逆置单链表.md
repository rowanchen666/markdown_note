# 要求：逆置单链表，时间复杂度O(N)
```c++
  struct ListNode {
      int val;
      ListNode* next;
      ListNode() : val(0), next(nullptr) {}
      ListNode(int x) : val(x), next(nullptr) {}
      ListNode(int x, ListNode* next) : val(x), next(next) {}
  };
```
对于如上单链表结点，要实现单链表逆置功能

### way1：使用栈

```c++
ListNode* reserve(ListNode* head) {
    //处理空链表
    if (head = nullptr) return nullptr;
    //处理只有一个结点的链表
    if (head -> next == nullptr) return head;

    ListNode* p = head, *result_head = nullptr;
    stack<int> temp;

    //把结点值压入栈
    while (p != nullptr) {
        temp.push(p -> val);
        p = p -> next;
    }

    //创建新结点
    result_head = new ListNode (temp.top());
    temp.pop();
    ListNode* current = result_head;

    while (!temp.empty()) {
        current->next = new ListNode (temp.top());
        temp.pop();
        current = current->next;
    }

    return result_head;
}
```

##### 复杂度分析：时间复杂度O(N)，空间复杂度O(N)

### way2:递归法

```c++
ListNode* reserve(ListNode* head) {
    //传入空链表或只有一个结点
    if (head == nullptr || head -> next == nullptr) return head;

    //分治思想：
    //先处理子链表：通过递归，找到链表的尾结点，并且逐层返回
    ListNode *newhead = reserve(head -> next);
    //再处理当前结点
    head -> next -> next = head;
    head -> next = nullptr;

    return newhead;
}
```

##### 图解递归过程:
```
  原链表：1 -> 2 -> 3 -> nullptr

  递归调用：
  reverseList(1) -> reverseList(2) -> reverseList(3) -> return 3

  回溯过程：
  步骤1: 处理节点2和3的关系
     1 -> 2    3 -> nullptr
          ↑    ↓
          └────┘
     结果：1 -> 2 <- 3, newHead = 3

  步骤2: 处理节点1和2的关系
     1    2 <- 3, newHead = 3
     ↓    ↑
     └────┘
     结果：nullptr <- 1 <- 2 <- 3, newHead = 3

  最终：3 -> 2 -> 1 -> nullptr
```

##### 复杂度分析：时间复杂度O(N)，空间复杂度O(n)

### way3:迭代法

```c++
ListNode* reserve(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* current = head;
    while (current != nullptr) {
        ListNode* next = current -> next;
        current -> next = prev;
        prev = current;
        current = next;
    }

    return prev;
}
```

##### 图解迭代过程
```
  原链表：1 -> 2 -> 3 -> 4 -> nullptr

  步骤1：prev=null, current=1
         null <- 1    2 -> 3 -> 4 -> null
                ↑     ↑
              prev  current

  步骤2：prev=1, current=2
         null <- 1 <- 2    3 -> 4 -> null
                      ↑    ↑
                    prev  current

  步骤3：prev=2, current=3
         null <- 1 <- 2 <- 3    4 -> null
                           ↑    ↑
                          prev  current

  步骤4：prev=3, current=4
         null <- 1 <- 2 <- 3 <- 4    null
                                ↑     ↑
                               prev  current

  最终：4 -> 3 -> 2 -> 1 -> null
```

##### 复杂度分析：时间复杂度O(N)，空间复杂度O(1) -> 更加简单，空间效率高
