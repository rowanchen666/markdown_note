# 进制的表示

1. 十进制：一般默认为十进制
2. 二进制：以`ob`或者是`0B`开头
```c++
int num1 = ob1010;
int num2 = oB1010;
```
3. 八进制：以`0`开头
```c++
int num = 01234;
```
4. 十六进制：以`0x`或者是`0X`开头
```C++
int num1 = 0xffff;
int num2 = oXFFFF;  //注意大小写统一
```

# 进制的转化

## 基于输出

基本格式：`cout << 类型 << num;`
eg：
```c++
int num = 65535;
cout << hex << num;  //十六进制，输出结果为ffff
cout << oct << num;  //八进制，输出结果为177777
cout << dec << num;  //十进制，输出结果为65535
```

## 转化为字符串

```c++
#include <iostream>
#include <sstream>
#include <iomanip>
#include <bitset>
#include <string>
using namespace std;

  

int main() {
    int num = 42;
    // 转换为十六进制字符串
    stringstream ss_hex;
    ss_hex << hex << num;
    string hex_str = ss_hex.str();
    
    // 转换为八进制字符串
    stringstream ss_oct;
    ss_oct << oct << num;
    string oct_str = ss_oct.str();
    
    // 转换为二进制字符串（使用bitset）
    string bin_str = bitset<8>(num).to_string();
    
    cout << "十进制: " << num << endl;
    cout << "十六进制: " << hex_str << endl;
    cout << "八进制: " << oct_str << endl;
    cout << "二进制: " << bin_str << endl;

    return 0;

}
```
