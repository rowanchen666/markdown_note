要求：删除字符串s1中所有s2中的字符

```c++
void squeeze (char s1[] , const char s2[]) {
    int i , j , k  ;
    for (j = 0 ; s2[j] != '\0' ; j ++) {
        for (i = k = 0 ; s1[i] != '\0' ; i ++) {
            if (s1[i] != s2[j] ) {
                s1[k++] = s1[i] ;
            }
        }
        s1[k] = '\0' ;
    }
}
```

简化版：删除字符串s中所有的特定字符

```c++
void squeeze (char s[] , char ch) {
	int i , j;
	for (i = j = 0 ; s[i] != '\0' ; i ++) {
		if (s[i] != ch) {
			s[j ++] = s[i];  //相当于从后往前覆盖
		}
	}
	s[j] = '\0';
}
```

[注意 1] ： 代码中<font color = 'red'>j++不可以写为++j</font>，但可以改写为`s[j] = s[i]; j++;`，核心在于先对原位进行覆盖，再把指针向后挪。
[注意 2]：参数里的`char ch`可以改写为`int n`，因为比较时会自动将字符类型转为整型。
[注意 3]：从简化版到完整版两个问题的过渡，关键在于想明白谁作为内层循环，谁作为外层循环。
