# 迷宫最短路径求解算法

## 程序概述

本程序使用广度优先搜索（BFS）算法来寻找迷宫中从起点(0,0)到终点(row-1,col-1)的最短路径。

## 程序要求

1. **输入要求**：
   - 迷宫尺寸（行数和列数）
   - 迷宫矩阵：0表示通道，其他数值表示墙

2. **输出要求**：
   - 显示最短路径长度
   - 显示完整路径坐标序列
   - 如果无解，提示"没有找到路径"

3. **算法要求**：
   - 使用BFS算法保证找到最短路径
   - 正确处理边界条件
   - 避免内存泄漏

## 算法思路

### 核心思想
使用广度优先搜索（BFS）算法，因为BFS能够保证找到的第一条路径就是最短路径。

### 具体步骤

1. **初始化阶段**：
   - 创建动态二维数组存储迷宫
   - 将起点(0,0)的距离设为1
   - 将起点加入队列

2. **BFS搜索阶段**：
   - 从队列中取出当前位置
   - 检查是否到达终点，如果到达则结束搜索
   - 按上、右、下、左四个方向探索相邻位置
   - 对于每个可通行的相邻位置：
     - 设置距离值为当前位置距离+1
     - 将其加入队列继续搜索

3. **路径重构阶段**：
   - 从终点开始，寻找距离值递减的相邻位置
   - 逐步回溯到起点，构建完整路径

## 程序重点

### 1. 边界检查
```cpp
// 正确的边界检查
if (last.x > 0 && maze[last.x - 1][last.y] == 0)  // 上方
if (last.y < col - 1 && maze[last.x][last.y + 1] == 0)  // 右方
if (last.x < row - 1 && maze[last.x + 1][last.y] == 0)  // 下方
if (last.y > 0 && maze[last.x][last.y - 1] == 0)  // 左方
```

### 2. 距离标记策略
- 起点标记为1（而不是0）
- 每个新发现的位置标记为前一位置的距离+1
- 利用距离值进行路径回溯

### 3. 路径重构算法
```cpp
// 从终点向起点回溯
while (pathIndex >= 0) {
    path[pathIndex] = cur;
    // 寻找距离值为currentDistance-1的相邻位置
    int currentDistance = maze[cur.x][cur.y];
    // ... 检查四个方向
}
```

## 原代码问题分析

### 问题1：数组越界访问
**原代码问题**：
```cpp
// 危险的边界检查
if (last.x != 0 && maze[last.x - 1][last.y] == 0)  // 可能越界
if(maze[last.x + 1][last.y] == 0)  // 没有检查下边界
```

**问题分析**：
- `last.x != 0` 不能保证 `last.x - 1` 不会越界
- 没有检查 `last.x + 1 < row` 可能导致访问超出数组范围的内存

**修复方案**：
```cpp
// 安全的边界检查
if (last.x > 0 && maze[last.x - 1][last.y] == 0)  // 确保索引>=0
if (last.x < row - 1 && maze[last.x + 1][last.y] == 0)  // 确保不超出范围
```

### 问题2：起点距离初始化错误
**原代码问题**：
```cpp
cur.x = 0;
cur.y = 0;
st.push(cur);  // 起点距离为0（默认值）
```

**问题分析**：
- 起点distance为0，导致后续距离计算错误
- BFS中距离为0的位置会被误认为是未访问的通道

**修复方案**：
```cpp
cur.x = 0;
cur.y = 0;
maze[0][0] = 1;  // 明确设置起点距离为1
st.push(cur);
```

### 问题3：出口检测逻辑错误
**原代码问题**：
```cpp
if (last.x == row - 1 && last.y == col - 2) break;  // 错误的出口位置
```

**问题分析**：
- 出口应该是 `(row-1, col-1)`，而不是 `(row-1, col-2)`
- 这会导致算法在错误的位置停止搜索

**修复方案**：
```cpp
if (last.x == row - 1 && last.y == col - 1) {
    found = true;
    break;
}
```

### 问题4：复杂且错误的路径回溯
**原代码问题**：
```cpp
while (cur.x != 0 || cur.y != 0) {
    path[maze[cur.x][cur.y]] = cur;  // 直接用距离值作为索引
    // 复杂的条件判断...
}
```

**问题分析**：
- 直接用距离值作为数组索引容易出错
- 路径重构逻辑复杂，难以保证正确性
- 可能导致路径不完整或顺序错误

**修复方案**：
```cpp
int pathIndex = length - 1;
while (pathIndex >= 0) {
    path[pathIndex] = cur;
    pathIndex--;
    // 寻找距离值恰好小1的相邻位置
    int currentDistance = maze[cur.x][cur.y];
    // 系统性地检查四个方向
}
```

### 问题5：内存泄漏
**原代码问题**：
```cpp
maze = new int* [row];
// ... 使用maze
// 程序结束时没有释放内存
return 0;
```

**问题分析**：
- 动态分配的二维数组没有释放
- 路径数组也没有释放
- 长期运行会导致内存泄漏

**修复方案**：
```cpp
// 释放二维数组
for (i = 0; i < row; i++) {
    delete[] maze[i];
}
delete[] maze;
delete[] path;
```

### 问题6：缺少无解情况处理
**原代码问题**：
- 没有检查是否找到了有效路径
- 即使无解也会尝试构建路径，可能导致错误

**修复方案**：
```cpp
if (!found) {
    cout << "没有找到从起点到终点的路径！" << endl;
    // 释放内存并返回
    return 0;
}
```

## 算法复杂度

- **时间复杂度**：O(V + E)，其中V是可访问的格子数，E是相邻关系数
- **空间复杂度**：O(V)，用于存储队列和距离信息
