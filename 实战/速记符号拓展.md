### 编写函数expand（s1,s2），将字符串s1中类似于a-z一类的速记符号在字符串s2中扩展为等价的完整列表abc…xyz。该函数可以处理大小写字母和数字，并可以处理a-b-c、a-20-9与-a-2等类似的情况。作为前导和尾随的-字符原样排印。

#### 1. 错误样例

```c++
void expand (char s1[] , char s2[]) {
    int i , j;
    for (i = 0 ; s1[i] != '\0' ; i++){
        if (s1[i] == '-' && isdigit(s1[i+1]) && isdigit(s1[i-1])){
            for (j = i - 1 ; j < s1[i + 1] -s1[i - 1] ; j ++) {
                s2[j] = s1[i - 1] + (j - (i - 1));
            }
        }
        else if (s1[i] == '-' && isalpha(s1[i+1]) && isalpha(s1[i-1])){
            for (j = i - 1 ; j < s1[i + 1] -s1[i - 1] ; j ++) {
                s2[j] = s1[i - 1] + (j - (i - 1));
            }
        }
    }
}
```

#### **问题总结**：

###### 1. 代码问题：

1. 下标越界问题：`si[i - 1]`和`s1[i + 1]`可能会造成下标越界。

2. `s2[]`最后没有添加`\0`作为终止。

3. 没有处理非扩展部分的字符

###### 2. 逻辑问题：

1. 没有考虑大小写问题，例如`"a-Z"`。

2. 没有考虑顺序问题，例如`"z-a"`。

3. 循环条件 `j < s1[i+1] - s1[i-1]` 是错误的，应该是 `j <= s1[i+1] - s1[i-1] + (i-1)` 或类似逻辑，实际上扩展应该产生从 `s1[i-1]+1` 到 `s1[i+1]-1` 的字符。

4. 对`s2`的输入有问题，每次的`j = i - 1`会使得下一次的输入覆盖部分上一次的输入

#### 2. 正确示例

```c++
void expand (char s1[] , char s2[]) {
    int i , j;
    for (i = 0 ; i < strlen(s1) ; i ++) {
        if(i + 2 < strlen(s1) && s1[i + 1] == '-') {
            char start = s1[i];
            char end = s1[i + 2];
  
            if ((islower(start) && islower(end) && start < end) ||
                (isupper(start) && isupper(end) && start < end) ||
                (isdigit(start) && isdigit(end) && start < end)) {
                for (char c = start; c <= end; c++) {
                    s2[j++] = c;
                }
                i += 3;
            } else {
                s2[j++] = s1[i];
            }
        }
    }
    s2[j] = '\0';  
}
```

**改进地方：** 

1. 将对`s1`下标的判断提前，避免并减少后续判断时条件的复杂程度，

2. 对`s2`进行输入是，不再以j作为循环变量，而是发挥其在函数内的全局性，进行总的计数，而输入则直接用字符输入，并且以字符作为循环变量，没有下标重复的问题，也方便对普通字符的录入。
